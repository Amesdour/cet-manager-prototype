# Landfill / CET Tracker — Generic Prototype

This is a **generic, standalone version** of a technical waste-management (CET) operations
platform. It is provided as an independent software product for IP registration and
demonstration purposes.

All organization names, client records, employee names, addresses, phone numbers, NIF/RC
numbers, and bank details have been replaced with generic placeholder data. No real client,
partner, or personal information is included in this codebase.

## What the software does

- Gate management for waste discharge / intake at technical landfill (CET/CDI) sites
- Client and contract management (state, private, cash, prepaid client types)
- Invoice generation and billing (tonnage-based, per-discharge, and full-payment models)
- Role-based access control (Admin / Operator) across multiple sites
- Compliance features aligned with Algerian personal data protection law (Loi 18-07)
